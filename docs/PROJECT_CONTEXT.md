# Restaurant Booking System Context

## Overview

Restaurant Booking System adalah aplikasi web fullstack untuk reservasi meja restoran.

Aplikasi memiliki dua role:

1. User
2. Admin

Backend sudah selesai dibuat menggunakan:

- Node.js
- Express.js
- MySQL
- JWT Authentication

Frontend akan dibangun menggunakan:

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Axios

---

## User Features

- Register
- Login
- Logout
- Melihat daftar meja
- Membuat booking
- Melihat riwayat booking
- Membatalkan booking

---

## Admin Features

- Login
- Melihat seluruh booking
- Approve booking
- Reject booking
- CRUD meja

---

## Booking Status

- pending
- approved
- rejected
- cancelled
- expired
